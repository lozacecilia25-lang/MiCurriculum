# Instrucciones del repositorio

Cuando el usuario pida acciones de Git en esta carpeta, actuar siempre sobre el repositorio `C:\IAGenerativa\Clase06_Ejercicio28`.

## Comandos acordados

- **"subí los cambios"**: hacer `git add` de los cambios relevantes, crear un `git commit` con un mensaje que explique qué cambió y luego hacer `git push`.
- **"bajá los cambios"**: hacer `git pull`.
- **"guardá una versión"**: hacer solo `git commit` (con `git add` previo de los cambios relevantes), sin `push`.

## Registro

- Mantener actualizado `HISTORIAL.md` con las acciones realizadas.
- Mantener actualizado `README.md` con el resumen/historial visible del proyecto.
